# 라이트닝 바카라 토너먼트

실제 현금 입출금 없이 게임용 칩으로 진행하는 20인 실시간 토너먼트입니다.

## 실시간 참가 방식

- 같은 Render 링크로 접속한 사용자는 1~20번 빈 좌석을 직접 선택합니다.
- 닉네임은 중복 사용할 수 없으며, 착석 상태는 모든 접속자에게 즉시 공유됩니다.
- 접속 중인 참가자는 초록불, 연결이 끊긴 참가자는 빨간불로 표시됩니다.
- 같은 기기로 다시 접속하면 기존 좌석을 자동 복구합니다.

## 규칙

- 최대 20석, 바이인 200,000칩
- 플레이어/뱅커/타이/플레이어 페어/뱅커 페어 베팅
- 모든 베팅금에 수수료 20% 추가 차감
- 매 라운드 1~5개 라이트닝 카드에 2x/3x/4x/5x/8x 배수 부여
- 2,000,000칩 이상이면 보유금이 가장 많은 참가자 우승
- 목표 미달 시 최후 1인 우승
- 서버가 모든 카드, 정산, 잔액과 승자를 판정

## 로컬 실행

```bash
npm install
ADMIN_PASSWORD=9981 npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 관리자 비밀번호는 `9981`입니다.

## Render

GitHub 저장소를 Render의 Blueprint로 연결하면 `render.yaml`을 읽어 자동 설정됩니다. 무료 인스턴스가 재시작되면 진행 중 게임은 초기화됩니다.
